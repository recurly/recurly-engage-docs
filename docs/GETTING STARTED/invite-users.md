### Prerequisites

<ul class="rp-list">
  <li>You must have <strong>Company</strong>, <strong>App Administrator</strong>, or <strong>App Member</strong> permissions in Recurly Engage.</li>
</ul>

# Definition

<div class="rp-definition">Inviting users lets administrators grant team members access to specific applications in Recurly Engage and control what actions they can perform, based on their permission level.</div>

# Key benefits

<div class="rp-benefits">
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-sliders" aria-hidden="true"></i></div>
    <strong>Granular access control</strong>
    <span>Assign precise permissions per user and per app to maintain security and accountability.</span>
  </div>
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-paper-plane" aria-hidden="true"></i></div>
    <strong>Streamlined onboarding</strong>
    <span>Send invitations directly from the console for fast user setup.</span>
  </div>
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-users-gear" aria-hidden="true"></i></div>
    <strong>Flexible team management</strong>
    <span>Grant or revoke access across multiple apps without creating additional accounts.</span>
  </div>
</div>

# Key details

Administrators can invite users to individual apps in Recurly Engage. To grant a user access to multiple apps, send a separate invitation for each one. Only company or app administrators can modify settings and invite users.

## Add a user

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open the Add user form</h4><p>In the Recurly Engage console, go to <strong>Settings > Users</strong> and click <strong>Add user</strong>.</p></div>
  </div>
</div>
