# Key details

The following outlines the most popular uses of Recurly Engage across the customer lifecycle. Churn-related use cases are often the starting point for many customers.

## Acquisition

<div class="rp-nav-grid">

<Cards>
  <Card title="Abandon Cart" href="https://docs.recurly.com/recurly-engage/docs/abandon-cart" target="_blank">
    Prompt exiting and return visitors who started signup to finish or resume checkout.
  </Card>
  <Card title="1-Click Resubscribe" href="https://docs.recurly.com/recurly-engage/docs/one-click-resubscribe" target="_blank">
    Customize the flow for churned users to resubscribe with one click.
  </Card>
  <Card title="Increase Registration">
    Prompt engaged visitors to submit email or mobile info contextually.
  </Card>
  <Card title="Personalize by Source">
    Tailor the site experience for SEM, SEO, partner, or organic visitors.
  </Card>
</Cards>
</div>

## Engagement

<div class="rp-nav-grid">

<Cards>
  <Card title="Personalized Onboarding" href="https://docs.recurly.com/recurly-engage/docs/personalized-onboarding" target="_blank">
    Onboard new users with prompts that surface only unused features.
  </Card>
  <Card title="Boost App Installs">
    Use a survey to guide users to install and activate on other platforms.
  </Card>
  <Card title="Increase Feature Adoption">
    Personalize feature discovery based on usage patterns.
  </Card>
  <Card title="Increase Editorial Impact">
    Let your content team surface recommendations in-app.
  </Card>
  <Card title="Improve Error Experience">
    Prompt users experiencing errors with acknowledgement or an offer.
  </Card>
</Cards>
</div>
