### Limitations

<ul class="rp-list">
  <li>Templates are available for prompts and guides on desktop and mobile web</li>
  <li>Creating and saving your own custom templates isn't currently supported</li>
</ul>

# Definition

<div class="rp-definition">A template is a pre-built prompt or guide, mapped to a common subscriber lifecycle use case, that you select when creating new content. Choosing a template creates a new draft with preset configuration already filled in, so you go straight to refining instead of building from scratch. Templates are grouped into four use-case categories: churn prevention, involuntary churn, winback, and acquisition and onboarding.</div>

## Create a prompt from a template

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open the new prompt flow</h4><p>From the Engage dashboard, select + New prompt. The New prompt modal opens with the Template library displayed, grouped by use case.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Choose a template</h4><p>Browse the categories and select the template that matches your goal — for example, Cancel save under Churn prevention. A new prompt draft is created with preset copy and layout already filled in.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Refine and launch</h4><p>You land in the Prompt editor, where you can refine the content and launch.</p></div>
  </div>
</div>

<div class="rp-callout rp-callout-tip">
  <div><strong><i class="fa-solid fa-lightbulb" aria-hidden="true"></i> Tip</strong>To build a prompt without a template, scroll to the Custom Prompts section, which stays available in the modal.</div>
</div>

## Create a guide from a template

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open the new guide flow</h4><p>From the Engage dashboard, select + New guide. The New guide modal opens with the template library displayed, grouped by use case.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Choose a template</h4><p>Select the template that matches your goal — for example, Payment failure under Involuntary churn. A new guide draft is created with all preset configuration filled in, including the guide name, description, and segment, plus the required launch fields for that use case.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Review and launch</h4><p>You land in the guide editor to review, customize, and launch.</p></div>
  </div>
</div>

<div class="rp-callout rp-callout-tip">
  <div><strong><i class="fa-solid fa-lightbulb" aria-hidden="true"></i> Tip</strong>To build a guide without a template, scroll to the Custom Guides section, which stays available in the modal.</div>
</div>
