<div class="rp-page">
<div class="rp-overview">AI Style Studio is a chat assistant in the Recurly Engage prompt editor. Describe the change you want — "make the primary button larger", "change the header color to #FFD706" — and it writes the CSS and updates the live preview as it works. Changes apply to desktop and mobile by default, and every session is undoable, so you can experiment freely.</div>
<div class="rp-plan"><i class="fa-solid fa-key" aria-hidden="true"></i> AI Style Studio is available as part of testing period. Access and usage limits may vary.</div>

# Definition

<div class="rp-definition">AI Style Studio is an AI assistant in the prompt editor that restyles your prompts from plain-language requests. It works with any prompt type that uses CSS.</div>

# Key benefits

<div class="rp-benefits">
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>No CSS knowledge required</strong><span>Describe the change you want in plain language and the assistant writes the styles for you.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Live preview</strong><span>Every request is applied to your prompt as the assistant works, so you see results immediately.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Desktop and mobile</strong><span>Changes apply to both surfaces by default, or target one with a single phrase.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Safe to experiment</strong><span>Undo a change, reset the session, or revert all changes from the session in one click.</span></div>
</div>

# Step-by-step guide

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">1</div><div><h4>Navigate to your prompt</h4><p>Create a new prompt or go to an existing prompt.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">2</div><div><h4>Open the Design with AI tab</h4><p>Open a prompt in the editor and select the <strong>Design with AI</strong> tab, next to Properties.</p></div></div>
</div>

<div class="rp-callout rp-callout-tip">
<div><strong><i class="fa-solid fa-lightbulb" aria-hidden="true"></i> Best practice</strong>Changes apply to desktop and mobile by default. To style one surface only, add "on desktop" or "on mobile" to your request — for example, "increase the headline font size on mobile".</div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">3</div><div><h4>Describe your change and watch the preview</h4><p>Type what you want in plain language and keep refining until the prompt looks right. Use <strong>Undo</strong>, <strong>Reset</strong>, or <strong>Revert all changes from this session?</strong> whenever you need to step back.</p></div></div>
</div>

Once the prompt looks right, click <strong>Save & Exit</strong> to apply your changes.
