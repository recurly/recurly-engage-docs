  <div class="rp-plan"><i class="fa-solid fa-key" aria-hidden="true"></i> Available on all Recurly plans</div>

### Prerequisites

<ul class="rp-list">
  <li>You must be an active Recurly Engage member. If you're not, <a href="https://recurly.com/product/engage/" target="_blank">book a demo</a>.</li>
</ul>

# Definition

<div class="rp-definition">Cloning copies an existing prompt to another app, or to another guide within the same app, so you don't have to re-create it manually.</div>

# Key benefits

<div class="rp-benefits">
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-equals" aria-hidden="true"></i></div>
    <strong>Consistency</strong>
    <span>Maintain a consistent brand voice and customer experience without manually re-creating prompts across apps.</span>
  </div>
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-timeline" aria-hidden="true"></i></div>
    <strong>Streamlined workflows</strong>
    <span>Build and test prompts in a staging environment, then deploy them to your live apps. You save time and reduce the risk of errors.</span>
  </div>
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div>
    <strong>Improved accuracy</strong>
    <span>Minimize mistakes by copying an exact duplicate of a prompt that's already been tested and approved.</span>
  </div>
</div>

# Clone a prompt to another app

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open Prompts</h4><p>Go to the <span style={{fontWeight: "bold"}}>Prompts</span> section in <span style={{fontWeight: "bold"}}>Pulse</span>, the Recurly Engage management console.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/1c8edf0bff860a296a3f64eeddf3b9364d05dcda1a38e529da1db782d76bef28-clone_1.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Select a prompt</h4><p>From the <span style={{fontWeight: "bold"}}>All Prompts</span> section, select the prompt you'd like to clone.</p></div>
  </div>
</div>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Start the clone</h4><p>Select the <span style={{fontWeight: "bold"}}>+ Clone</span> button and choose the app you want. Alternatively, open the prompt and select <span style={{fontWeight: "bold"}}>Clone</span> from the <span style={{fontWeight: "bold"}}>Manage</span> dropdown menu.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/1ed2be9ed897fcc7abec030b618dcc95af023db4cad18e683ae3ee283a6f1806-clone_3.png" align="center" width="75%" border={true} />



<Image src="https://files.readme.io/aa8145c97624b1196784a36adcd0d6344c01ecc3a53dda75bcfcc46231264406-clone_2.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Choose the destination app</h4><p>In the <span style={{fontWeight: "bold"}}>Clone Prompt</span> modal, select the app you'd like to clone the prompt to.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/4ae585aeed23b8589aa4acec5c88ef0c2318ce6cdbe386412a03a571e3aaa6a7-clone_4.png" align="center" width="75%" border={true} />


<div class="rp-callout rp-callout-important">
  <div><strong><i class="fa-solid fa-circle-exclamation" aria-hidden="true"></i> Important</strong>After cloning, reset the custom goals, actions, triggers, experiments, and segments on the cloned prompt.</div>
</div>

# Clone a prompt to another guide

You can clone an existing prompt from one guide to another within the same app, without re-entering it manually.

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open the prompt</h4><p>Navigate to a guide and select the prompt you want to clone.</p></div>
  </div>
</div>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Choose Clone</h4><p>Select <span style={{fontWeight: "bold"}}>Manage</span>, and then select <span style={{fontWeight: "bold"}}>Clone</span>.</p></div>
  </div>
</div>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Select the destination</h4><p>In the <span style={{fontWeight: "bold"}}>Clone Prompt</span> modal, select the app and the guide you'd like to clone the prompt to.</p></div>
  </div>
</div>
