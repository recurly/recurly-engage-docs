### Prerequisites

<ul class="rp-list">
<li>Company, App Administrator, or App Member permissions in Recurly Engage.</li>
</ul>

# Definition

<div class="rp-definition">An overlay prompt is a message that renders on top of your interface, with varying levels of interruption depending on the format you choose.</div>

# Key benefits

<div class="rp-benefits">
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Maximum visibility</strong><span>Command user focus at critical moments.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Format flexibility</strong><span>Choose from full-screen interstitials to subtle notifications.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Custom behavior</strong><span>Control size, timing, and dismissal for the best user experience.</span></div>
</div>

# Key details

Overlay prompts render above your content and can either fully block interaction—interstitial, pop-up, and video formats—or sit unobtrusively alongside it, like notification and bottom banner formats.


<Image src="https://files.readme.io/eb0dc55-image.png" align="center" width="75%" border={true} />


## Interstitial

Full-screen or near-full-screen prompts shown before or after page load. They respect device aspect ratios and safe-area margins to keep key content visible.


<Image src="https://files.readme.io/0ab0f6f-image.png" align="center" width="75%" border={true} />


## Pop-up

Overlay windows featuring an image, text, and one or more calls to action. Users can dismiss them if you configure them to allow it.

**Sizes**: 1200×800, 960×640, or 750×500 (configurable).


<Image src="https://files.readme.io/d2cb3d2-image.png" align="center" width="75%" border={true} />


## Video

Media-rich overlays that combine video playback with text and actionable buttons.

**Size**: 1100×619 (configurable).


<Image src="https://files.readme.io/5b26f7a-image.png" align="center" width="75%" border={true} />


## Notification

Subtle corner prompts with a brief headline, background image, and a single call to action—ideal for low-impact messaging.


<Image src="https://files.readme.io/45dbbcc-image.png" align="center" width="75%" border={true} />


## Bottom banner

Banner prompts that span the bottom of the viewport, displaying text and imagery without fully blocking content.


<Image src="https://files.readme.io/1500b39-image.png" align="center" width="75%" border={true} />


# Step-by-step guide

Follow these steps to build, publish, and activate an overlay prompt.

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">1</div><div><h4>Start a new prompt</h4><p>Go to <strong>Prompts > +New Prompt</strong>.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">2</div><div><h4>Choose your overlay type</h4><p>Select <strong>Desktop and Mobile</strong>, then choose your overlay type—for example, <strong>Pop-up</strong>.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">3</div><div><h4>Name it</h4><p>Add a name and an optional description.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">4</div><div><h4>Add segments</h4><p>Add one or more segments.</p></div></div>
</div>

Adding the <strong>Test Users</strong> segment lets you view the prompt as if you were a targeted user.

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">5</div><div><h4>Add a trigger</h4><p>Choose when the prompt fires.</p></div></div>
</div>

Learn more about triggers <a href="triggers" target="_blank">here</a>.

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">6</div><div><h4>Set a limit (optional)</h4><p>Cap how often the prompt can appear.</p></div></div>
</div>

There are multiple types of limits; see <a href="limits-1" target="_blank">limits</a>.

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">7</div><div><h4>Set a schedule (optional)</h4><p>Select <a href="schedule-1" target="_blank">Schedule</a> to configure timing.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">8</div><div><h4>Set an action (optional)</h4><p>Define what happens after a click via <a href="actions-1" target="_blank">Actions</a>.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">9</div><div><h4>Design the prompt</h4><p>Select <strong>Edit prompt design</strong> to design the prompt.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">10</div><div><h4>Preview and continue</h4><p>Adjust the settings in the preview, then select <strong>Continue</strong> when you're done.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">11</div><div><h4>Preview on your live site</h4><p>Preview the prompt on your live site.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">12</div><div><h4>Save and start</h4><p>When you're satisfied, select <strong>Save</strong> and set the status to <strong>Start</strong>.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">13</div><div><h4>Test the prompt</h4><p>Validate your setup with the <strong>Test Users</strong> segment.</p></div></div>
</div>

See the <a href="test-users" target="_blank">test user guide</a> for details.

## Activate the prompt

Activation happens in two phases.

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">1</div><div><h4>Review phase</h4><p>Launch to the <strong>Test Users</strong> segment for final QA.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">2</div><div><h4>Active phase</h4><p>Attach all target segments for full-scale deployment.</p></div></div>
</div>

<div class="rp-callout rp-callout-note">
<div><strong><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Note</strong>You can pause, restart, or end a prompt at any time—just end any active experiment first.</div>
</div>
