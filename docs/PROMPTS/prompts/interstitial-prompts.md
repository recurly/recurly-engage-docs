<div class="rp-overview">Recurly Engage's enhanced SDK gives you granular button controls for interstitial prompts on HTML devices (including React Native), Roku, and Apple TV. Customize button dimensions, border radius, thickness and color, font size, and absolute positioning—all configured programmatically within the SDK.</div>
<div class="rp-plan"><i class="fa-solid fa-key" aria-hidden="true"></i> Available on all Recurly Engage plans</div>

# Key benefits

This enhanced functionality gives developers the flexibility to design highly customized, effective interstitial prompts for a wide range of use cases. The ability to precisely control button layouts—stacked or inline—is especially valuable for optimizing the user experience and driving specific outcomes.

<div class="rp-benefits">
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Enhanced customization</strong><span>Create unique button styles that align with your brand's design language.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Improved user experience</strong><span>Optimize button placement and layout to improve readability and user interaction.</span></div>
<div class="rp-benefit"><div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div><strong>Flexible design</strong><span>Tailor prompts for high-value use cases such as subscriber activation, engagement campaigns, involuntary churn reduction, and special offers.</span></div>
</div>

# Step-by-step guide

The new granular controls are configured programmatically within the SDK, simplifying the process of creating custom prompts.

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">1</div><div><h4>Create a new interstitial prompt</h4><p>In <strong>Pulse</strong>, the Recurly Engage management console, navigate to <strong>Prompts > + New Prompt</strong>. Select the <strong>Interstitial</strong> <a href="https://docs.recurly.com/recurly-engage/update/docs/prompts#/" target="_blank">prompt</a> type for the device type you're targeting.</p></div></div>
</div>


<Image src="https://files.readme.io/ef983cda52f1278237e68949b1d3fc6868ae3adf5dc1711a5ab08bb89fc49c25-Interstitial_1.png" align="center" width="75%" border={true} />


<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">2</div><div><h4>Configure your prompt details</h4><p>In the prompt's details section, configure your targeted <a href="https://docs.recurly.com/recurly-engage/docs/segments#/" target="_blank">segment</a>, trigger, limits, and schedule.</p></div></div>
</div>


<Image src="https://files.readme.io/771975700b27e6b44667ce690f4ec31325773b112c3f9166d70fa3a6d0172e57-Interstitial_2.png" align="center" width="75%" border={true} />


<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">3</div><div><h4>Edit the prompt design</h4><p>From the Prompt Details screen, open the Edit prompt design window and configure your prompt to match the messaging, styles, and interactions you want.</p></div></div>
</div>

<div class="rp-steps">
<div class="rp-step"><div class="rp-step-num">4</div><div><h4>Update the user interactions</h4><p>In the User Interaction section, update your buttons with personalized height, width, font size, border radius, thickness and color, and positioning.</p></div></div>
</div>
