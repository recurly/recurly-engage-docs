### Prerequisites

<ul class="rp-list">
  <li>You must have <strong>Company</strong>, <strong>App Administrator</strong>, or <strong>App Member</strong> permissions in Recurly Engage.</li>
  <li>Your site must load the Recurly Engage JavaScript (JS) snippet with Preview enabled.</li>
  <li>You must have created at least one segment (<a href="/recurly-engage/docs/segments" target="_blank">Create a segment</a>) and one inline prompt (<a href="/recurly-engage/docs/inlines" target="_blank">Create an inline</a>). These assets are the basis for your in-page testing.</li>
</ul>

# Definition

<div class="rp-definition">The Preview Tool is a point-and-click interface that overlays your live site, so you can manage and debug Recurly Engage elements (segments, trackers, prompts, and inline placements) in real time.</div>

# Key details

With Live Now, you can:

<ul class="rp-list">
  <li>Impersonate individual users to test personalized flows.</li>
  <li>View which segments a user matches.</li>
  <li>Preview any prompt or guide in context.</li>
  <li>Add usage trackers and triggers on the fly.</li>
  <li>Inspect inline prompts, and check their stats and placement with X-Ray.</li>
  <li>Visualize and override user traits in real time.</li>
  <li>Insert inline prompts without coding.</li>
</ul>

## Use the Preview Tool

The Preview Tool injects a toolbar into your site. Its core workflow lets you add inline prompts anywhere on the page with a simple click-and-select action.

### X-Ray for inline prompts

When your page contains many Recurly Engage components, use **X-Ray** mode to highlight all prompts and trackers. X-Ray overlays outlines and metrics, helping you locate items and understand their live performance.

Use these capabilities to test, validate, and fine-tune your Recurly Engage setup before you push changes live to your entire audience.
