# Definition

<div class="rp-definition">Design Tools integrations allow Recurly Engage to import designs from external tools and translate their layout, styling, and messaging into Engage prompts. They map elements such as titles, body copy, buttons, and survey options into an editable draft, with matching Cascading Style Sheets (CSS) generated automatically.</div>
