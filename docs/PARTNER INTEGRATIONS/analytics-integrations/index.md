# Definition

<div class="rp-definition">Analytics integrations allow Recurly Engage to send prompt impressions, clicks, dismissals, timeouts, and custom goal events directly to your analytics provider of choice, preserving session and user context.</div>

# Key details

Select an integration to see its setup details.

<div class="rp-nav-grid">

<Cards>
  <Card title="Google Analytics" href="/recurly-engage/docs/google-analytics" target="_blank">
    Track prompt events through the Google Analytics JavaScript software development kit (SDK) or the server-side Measurement Protocol.
  </Card>
  <Card title="Amplitude" href="/recurly-engage/docs/amplitude" target="_blank">
    Forward prompt interactions through the Amplitude JavaScript SDK, with optional inbound data sync through comma-separated values (CSV) files, webhooks, or the Export API.
  </Card>
  <Card title="Mixpanel" href="/recurly-engage/docs/mixpanel" target="_blank">
    Send prompt events and user traits using Mixpanel Service Accounts and a project token.
  </Card>
  <Card title="mParticle" href="/recurly-engage/docs/mparticle" target="_blank">
    Export prompt events and attributes to mParticle through a Custom Feed integration.
  </Card>
  <Card title="Heap">
    Capture prompt interactions using Heap's JavaScript SDK for automatic event capture.
  </Card>
  <Card title="Adobe Analytics" href="/recurly-engage/docs/adobe-analytics" target="_blank">
    Emit prompt events through the Experience Platform Web SDK (Alloy.js) to Adobe Analytics.
  </Card>
</Cards>
</div>
