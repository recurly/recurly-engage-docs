  <div class="rp-plan"><i class="fa-solid fa-key" aria-hidden="true"></i> Available on all Recurly plans</div>
  <div class="rp-card">

    <ul class="rp-list">
      <li><span style={{fontWeight: "bold"}}>Replicate issues:</span> Accurately reproduce and diagnose a reported issue or bug within your configuration.</li>
      <li><span style={{fontWeight: "bold"}}>Validate setup:</span> Confirm that new prompts, notifications, and logic are triggering correctly before they go live to your customers.</li>
      <li><span style={{fontWeight: "bold"}}>Walk through configuration:</span> Provide hands-on guidance or demonstrations using a safe, testable user profile.</li>

# Key steps

Follow these steps in Engage to create your test user:

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Navigate to settings</h4><p>Open Test Account Credentials from the Settings menu and create your test user using the sub-steps below.</p></div>
  </div>
</div>

<ol>
  <li>Log in to your Recurly Engage account.</li>
  <li>In the main navigation menu, click <span style={{fontWeight: "bold"}}>Settings</span>.</li>
  <li>In the Settings menu, click <span style={{fontWeight: "bold"}}>User ID Matching</span>.</li>
  <li>On the User ID Matching page, click <span style={{fontWeight: "bold"}}>Test Account Credentials</span>.</li>
  <li>When prompted, enter the necessary details for your test user.</li>
  <li>Click <span style={{fontWeight: "bold"}}>Save Changes</span> to finalize the test account.</li>
</ol>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Begin testing</h4><p>Once it's created, use this Test User ID to simulate events and preview how your configured prompts will be delivered to a user with that specific subscription status.</p></div>
  </div>
</div>
