### Prerequisites

<ul class="rp-list">
  <li>You must have <span style={{fontWeight: "bold"}}>Company</span> or <span style={{fontWeight: "bold"}}>App Administrator</span> permissions in Engage.</li>
</ul>

# Definition

<div class="rp-definition">A <span style={{fontWeight: "bold"}}>tag</span> is a label you assign to one or more prompts to group them for filtering, reporting, and frequency capping.</div>

# Key benefits

<div class="rp-benefits">
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div>
    <strong>Organize prompts</strong>
    <span>Group prompts by use case, campaign, or market for easier management.</span>
  </div>
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div>
    <strong>Unified analytics</strong>
    <span>View combined performance metrics (impressions, conversions, and click-through rate) across all prompts sharing a tag.</span>
  </div>
  <div class="rp-benefit">
    <div class="rp-benefit-icon"><i class="fa-solid fa-circle-check" aria-hidden="true"></i></div>
    <strong>Frequency control</strong>
    <span>Set per-tag frequency caps to limit how often users see any prompts with that tag.</span>
  </div>
</div>

# Create and manage tags

App admins can create default tags at the application level under **Settings → Tags**, or add new tags on the fly when editing a prompt.


<Image src="https://files.readme.io/4a443a46f12b41134aed1a8ccdb932aba86cbf2b20f37945c75d01712dd475da-image.png" align="center" width="75%" border={true} />


# Assign tags to prompts

When you create or edit a prompt, select existing tags or type to add a new one under **Details → Tags**.


<Image src="https://files.readme.io/a248fe5e233d5c15ec140885651bc2a1ef2e0e33dceee6cbb084ce3cc6a5ae9c-image.png" align="center" width="75%" border={true} />


# Filter and report by tag

Go to **Prompts**, click the filter icon in the **Tags** column, and choose a tag to see all associated prompts and their combined metrics.


<Image src="https://files.readme.io/ffa89a2acdc30406f18ce2a9655dac93d26eda3ca5e15a6e29ab57bf48213ba2-image.png" align="center" width="75%" border={true} />


# Frequency capping by tag

To limit how often prompts with a specific tag appear to users:

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Go to Tags settings</h4><p>Go to <span style={{fontWeight: "bold"}}>Settings → Tags</span>.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Edit your tag</h4><p>Click the edit (pencil) icon for your tag.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Set a custom frequency cap</h4><p>Under <span style={{fontWeight: "bold"}}>Frequency Cap</span>, select <span style={{fontWeight: "bold"}}>Custom</span>, configure the limit, and submit.</p></div>
  </div>
</div>
