The August 4 release brings one handy editor upgrade and a few behind-the-scenes fixes: you can now copy prompt settings between device types instead of rebuilding them, plus fixes for retention experiment surveys, fullscreen prompt display, and location-based segment matching.

| Release Date | **Feature**            | **Type**    | **Potential Impact** | **Description / Overview**                                                                                                                                                                                                                                                                                                                                                                                                                     |
| :----------- | :--------------------- | :---------- | :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aug 4        | **Engage Editor**      | Enhancement | Low                  | You can now copy a prompt's editor settings from one device type and paste them into another using Copy/Paste Properties (formerly Import/Export), available to anyone with prompt creation permissions — not just superadmins. This is useful when you want the same look and configuration across web, iOS, Android, and other device types without rebuilding the prompt from scratch. No action is required if you don't use this feature. |
| Aug 4        | **Engage Experiments** | Bug Fix     | Low                  | Fixed a bug where survey inputs on retention experiments could show data from the wrong variation.                                                                                                                                                                                                                                                                                                                                             |
| Aug 4        | **Engage Prompts**     | Bug Fix     | Low                  | Fixed a bug where fullscreen prompts could incorrectly display as inline tiles instead of taking over the full screen.                                                                                                                                                                                                                                                                                                                         |
| Aug 4        | **Engage Segments**    | Bug Fix     | Low                  | Fixed an issue where geographic (GEO) segments could incorrectly match based on the wrong location field. If your segments use location-based conditions, matching accuracy should now be improved.                                                                                                                                                                                                                                            |
