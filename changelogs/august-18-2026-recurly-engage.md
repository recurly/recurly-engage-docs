The August 18 release brings more control over subscription changes and a couple of handy workflow upgrades: you can now set proration and next bill date when Engage triggers a subscription change, plus a new dashboard filter for finding prompts and segments by URL path, and richer interaction event data showing which segment triggered a prompt.

| Release Date | **Feature**                                    | **Type**     | **Potential Impact** | **Description / Overview**                                                                                                                                             |
| :----------- | :--------------------------------------------- | :----------- | :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aug 18       | **Engage Proration & Next Bill Date**          | Enhancement  | Med                  | Subscription changes made through Engage now support proration settings and can set the next bill date, giving you more control over how mid-cycle changes are billed. |
| Aug 18       | **Engage Filter Prompts/Segments by URL Path** | Enhancements | Low                  | You can now filter running prompts and segments by URL path in the dashboard, making it easier to find what's active on a given page.                                  |
| Aug 18       | **Engage Prompt Interaction Events**           | Enhancement  | Low                  | The onPromptInteraction event now includes the segment(s) that triggered the prompt, so you can see exactly why it displayed.                                          |
