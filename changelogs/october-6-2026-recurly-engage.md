October 6, 2026 Release: This release adds more control over subscription-level coupon targeting and redirect timing in Engage Actions, a device type filter in the all-prompts metrics view, and a fix for experiment winners not updating the baseline prompt — alongside an updated Payment Failure segment default for newly onboarded merchants.

| Release Date | **Feature**                                           | **Type**     | **Potential Impact** | **Description / Overview**                                                                                                                                                                                                                                                                                                                                                                                    |
| :----------- | :---------------------------------------------------- | :----------- | :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Oct 6        | **Engage Actions — Coupon Plan Picker**               | Enhancement  | Med                  | You can now target subscription-level coupon actions to a specific plan using a new plan picker dropdown. Previously, this action always defaulted to the subscriber's first active subscription. For merchants with multiple subscriptions per account, this enables more precise coupon targeting. Leaving the picker blank preserves the existing default.                                                 |
| Oct 6        | **Engage Actions — Redirect Delay**                   | Enhancements | Med                  | The redirect website action now supports a configurable delay. Set a "Seconds to delay" value so subscribers have time to read the prompt before being redirected.                                                                                                                                                                                                                                            |
| Oct 6        | **Engage Experiments**                                | Bug          | Med                  | Fixed a bug where clicking "Use This" on an experiment winner did not update the baseline prompt in the console. This caused follow-up experiments to use the old content as their "Original" variation, and could cause "Pause" to overwrite the winner. The baseline now updates immediately after selecting a winner.                                                                                      |
| Oct 6        | **Engage Metrics — Device Type Filter**               | Enhancements | Med                  | The all-prompts metrics view now includes a device type filter. You can break out prompt performance by device category (Desktop, Mobile, SmartTV, Tablet, Embedded), giving you visibility into how each prompt performs across device types. Previously, only aggregate metrics were available in this view.                                                                                                |
| Oct 6        | **Engage Segments — Payment Failure (new merchants)** | Enhacements  | Med                  | The default Payment Failure segment provisioned for newly onboarded merchants has been updated to match both failed and past_due invoice statuses, and now filters to active users only so churned accounts are excluded. If you are an existing merchant using the out-of-the-box Payment Failure segment without customization, consider reviewing and applying the same criteria to your existing segment. |
